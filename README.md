# 个人生活网站

这是第一版个人网站原型，使用 React + Vite + TypeScript。

## 一键打开

1. 双击 `启动个人网站.cmd`。
2. 保持弹出的黑色窗口打开，等待浏览器自动打开。
3. 如果浏览器没有自动打开，再双击 `打开我的网页.url`，或者在浏览器输入 `http://127.0.0.1:5173/`。
4. 关闭黑色窗口就会停止网站，网页也会随之无法访问。

## 本地运行

```powershell
pnpm install
pnpm dev
```

打开终端显示的地址，通常是：

```text
http://127.0.0.1:5173/
```

## 内容编辑

本地开发模式左下角有一个 `DEV` 按钮，也可以按 `Ctrl + Shift + D` 打开内容编辑器。

- `常用内容`：按页面顺序编辑基本信息、地址信息、首屏文案、最近在做什么、关于我、工作与联系；图片路径默认收在“高级图片设置”中。
- `摄影管理`：编辑摄影模块的小标签、主标题和导语；添加、重命名、排序或删除分类；添加、删除、排序照片；上传图片并修改内容。删除分类时，照片会移动到“未分类”。
- `爱好管理`：编辑爱好模块文案，以及每个爱好的主标题、导语、详情和照片。
- `旅行管理`：编辑旅行模块文案，以及城市、路线顺序、导语和照片。
- `JSON`：修改全部正文和外观配置。`pageText` 控制文字，`appearance` 控制 PC/手机字号、页脚、`BACK TO TOP`、卡片圆角以及 PC 首页封面圆角。
- `字体设置`：可分别调整 PC/手机字体、导航字号、模块标签缩放、模块介绍缩放、自定义正文大小、标题缩放和间距。“自定义正文”只影响个人介绍、详情段落等内容，不会改变标题、标签和模块介绍。
- `保存内容`：写回 `src/content/site.json`，仅本地开发模式可用。

## 替换图片

先准备自己的图片，然后放到 `public/images/` 目录，再把 `src/content/site.json` 里的图片路径改成对应文件名。

首页图已经使用 `相关使用图片/首页图.jpg` 生成了优化后的 WebP 版本，放在 `public/images/`。其他图片仍是本地占位视觉素材，不会依赖外部网络。
